# DARKROOM · AI 照片暗房

一张照片，多种构图，多种表达。构图、调色、光学、空间、文字与版式在一个暗房里完成；
目标检测、主体分割、深度估计、生成式补全四个模型全部在浏览器本地运行，照片不离开本机。

## 运行

```bash
cd darkroom && python3 serve.py 5180
```

`serve.py` 是带跨源隔离头（COOP / COEP）的静态服务器，开启后 ONNX 推理可以使用多线程 WebAssembly。
用其它静态服务器也能运行，只是 AI 推理会退化为单线程。

## 冲洗工具（快捷键 1–9）

1. **推荐**：一键成片（智能构图 + AUTO 调色 + 按场景推荐风格），12 个主体感知版式
2. **构图**：6 个构图方案，支持 Roll、主体锁定、画幅自适配；透视校正（旋转 / 垂直 / 水平 + 自动校正，WebGL 单应性变换）
3. **调色**：9 个胶卷选项（含原片） + 12 项参数、AUTO 调色、日期戳、漏光、我的风格
4. **局部**：AI 主体 / 背景 / 深度范围 / 径向 / 渐变 / 画笔蒙版，红色蒙版预览；AI 消除（MI-GAN）
5. **光学**：AI 深度景深（按弥散圆分层虚化、散景高光、点击对焦），经典主体蒙版景深，快门拖影与追焦
6. **空间**：深度图、2.5D 相机（横移 / 纵移 / 推拉 / 焦平面 + 视角预设）、遮挡补全（主体分层 + 背景生成）、动态预览与 WebM 视频导出
7. **画布**：纯色 / 模糊 / 镜像 / 拍立得 / 胶片条，纹理；AI 扩图（目标画幅 + 留白 + 主体位置）
8. **文字**：AI 原创文案（中 / EN / 日 × 7 种风格）、热门趋势库（热度、来源、时效、适配度）、精选库、智能批注、字体包、文字置于主体后方
9. **版式**：模板、拼贴（网格 / 主次 / 大头贴 / 印样 / 拍立得墙 / 手账），贴纸与图层管理

画布下方可以 Roll 全部维度，构图、画布、文案、字体、调色五个维度都可以单独锁定。

## 批量工作流

- **批量导入**：多选或拖拽多张照片，全部进入片夹胶片条
- **同步设置**：把当前照片的调色、画布、画幅与构图、模板、光学、透视、局部、文字同步到选中照片；画幅与模板会按每张照片的主体重新计算
- **批量套用**：在片夹中对多个项目统一套用风格、模板或画幅
- **批量导出**：渲染为 JPG / PNG / WebP 并打包成一个 ZIP
- **拼贴**：用选中的照片创建拼贴项目

## 模型与许可

| 模型 | 用途 | 大小 | 许可 |

| EfficientDet-Lite0（MediaPipe） | 主体检测 | 4.6 MB | Apache-2.0 |
| DeepLab v3（MediaPipe） | 主体分割 | 2.7 MB | Apache-2.0 |
| Depth Anything V2 Small（int8 ONNX） | 深度估计 | 27 MB | Apache-2.0 |
| MI-GAN pipeline v2（ONNX） | 生成式补全 / 扩图 / 消除 | 28 MB | MIT |

运行时 `@mediapipe/tasks-vision` 0.10.14 和 `onnxruntime-web` 1.20.1 都已放在 `vendor/` 中，应用可离线运行
（界面字体仍从 Google Fonts 加载）。

单张照片的景深、快门和视角变化都属于**模拟与生成效果**，并不是恢复真实的拍摄参数。
胶片风格使用自有命名，不代表任何品牌的官方模拟。文案库为原创内容和通用表达，不收录歌词、影视台词。
导出的图片不包含 EXIF 和 GPS 信息。

- 保留并接通 6 组明朝 / 书法字体，9 种主体感知绕排（新增波浪、四边、放射）。字体加载依赖 Google Fonts；部分简体字回退到思源宋体。
- 28 种内置贴纸，支持 PNG / JPG / WebP / SVG 自定义导入（15 MB 上限，最长边缩到 2048），透明图层随项目存储。导入的 SVG 以图像栅格化，不注入 DOM。
- 12 种版式，新增光环诗集、书页留白、流动海报、四边诗笺。「换一批 / 只重新排版」切换到其他模板，遵守构图、画布、字体锁，保留手动贴纸。
- 常驻胶卷架：点击一卷即完整替换胶片参数；原片卷卸除所有调色。顶部「还原底片」清除所有编辑并还原最初导入的照片，支持撤销。
- 「熄灯」隐去工具和叠加辅助线，保留胶卷架；Esc 开灯。
- Live：同名 JPG/HEIC + MOV/MP4/WebM 配对导入、带内嵌 MP4 的动态 JPG、单独视频。时间轴预览、入出点裁剪（0.1–15 秒）、关键帧封面、静态图导出、无声动态视频或 JPG + 视频 + 编辑参数 ZIP 导出。原始视频随项目保存在 IndexedDB。

### Live 支持边界

这是浏览器本地的动态照片工作流，**不是原生 Apple Live Photo 编码器**。导出的包不含 Apple MakerNote 配对标识和 QuickTime 定时元数据，不会自动合成为 iPhone 相册实况照片。HEIC/HEVC/MOV 解码取决于浏览器；不支持时需转换为 JPG / H.264 MP4。视频导出优先 MP4，浏览器不支持时用 WebM，720 px、约 12 fps、无声；复杂效果的实时编码可能造成帧率或时长变化。

动态帧统一使用构图、透视、胶卷、画布、文字、贴纸和径向/渐变局部调整。静态 AI 消除、扩图、景深、主体/深度/画笔蒙版和 2.5D 不套到整段视频，避免把一帧的蒙版错误用于运动内容。封面仍可使用原有静态工具。
